Política de Privacidade – Brisa Contatos

Última atualização: 18 de novembro de 2026

1. Quem somos

O Brisa Contatos é um aplicativo interno, de uso pessoal e profissional do administrador do grupo Brisa (Brisa Locações de Enxovais Ltda, CNPJ 07.172.652/0001-52, Rua Carandaí, 300, Casa Verde, São Paulo/SP). Não é oferecido ao público.

2. Dados acessados

Com a autorização expressa do usuário na tela de consentimento do Google, o aplicativo pode acessar, conforme as permissões concedidas: contatos (Google People API), e-mails (Gmail), eventos de agenda (Google Agenda), arquivos (Google Drive) e planilhas (Google Sheets) da própria conta do usuário.

3. Finalidade

Os dados são usados apenas para organizar contatos, agenda, mensagens e documentos de trabalho do próprio usuário. Nenhuma ação de envio, exclusão ou alteração é feita sem a aprovação do usuário.

4. Compartilhamento

Os dados não são vendidos, alugados nem usados para publicidade. Podem ser processados por ferramentas contratadas pelo próprio usuário para operar o aplicativo (como Composio, Supabase e provedores de IA), somente para a finalidade acima.

5. Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Armazenamento e segurança

Os dados ficam armazenados apenas pelo tempo necessário, em serviços com acesso restrito ao administrador.

7. Seus direitos (LGPD)

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/connections e solicitar a exclusão dos dados pelo e-mail abaixo.
